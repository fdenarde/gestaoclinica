# Prompt — Relatório Offline do Robô WhatsApp

```text
Gere um relatório offline detalhado do robô WhatsApp para o período de [DATA INICIAL] até [DATA FINAL].

Importante:
- Não envie mensagens.
- Não inicialize o WhatsApp.
- Não gere QR Code.
- Use apenas a lógica atual do robô e os dados disponíveis/backup.
- O relatório deve mostrar exatamente quais mensagens seriam enviadas.

O relatório deve mostrar:
1. Mensagens de véspera.
2. Mensagens do dia/manhã.
3. Mensagens do dia/tarde.
4. Bloqueios/exclusões.

Para cada mensagem, informe:
- Responsável.
- Paciente.
- Telefone.
- Horário real da sessão.
- Texto completo da mensagem exatamente como seria enviada.

Não usar tabela como formato principal.
Usar blocos fáceis de ler.

Formato:

**Terça, 09/06/2026**

**Véspera, enviada em 08/06 para sessão de 09/06**

Responsável:
Paciente:
Telefone:
Horário real:
Mensagem:

Ao final, informe:
- Total de mensagens simuladas.
- Total de bloqueios.
- Total de exclusões.
- Riscos encontrados.
- Confirmação de que nenhuma mensagem foi enviada.
- Nota de segurança do robô WhatsApp de 0–100.
- Pergunte se desejo alguma melhoria ou correção relacionada ao assunto, considerando qualquer uma das pastas/conversas do projeto.
```
