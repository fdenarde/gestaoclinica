# Prompt — Análise Sem Alterar Arquivos

```text
Analise o projeto sem alterar nenhum arquivo.

Leia:
- PROJECT_CONTEXT.md
- skills/universais/auditor-risco.md
- skills/clinica/guardiao-logica-clinica.md
- skills/clinica/sincronismo-agenda-sessoes-pagamentos.md

Objetivo:
Identificar riscos, inconsistências e oportunidades de melhoria.

Regras:
- Não editar arquivos.
- Não fazer deploy.
- Não enviar WhatsApp.
- Não alterar dados.
- Não executar rotinas perigosas.
- Não inicializar WhatsApp.
- Não gerar QR Code.

Forneça:
1. Diagnóstico geral.
2. Riscos encontrados.
3. Arquivos que provavelmente precisariam de alteração.
4. O que deve ser preservado.
5. Plano seguro de correção.
6. Testes necessários.
7. Nota de avaliação:
   - Arquitetura
   - Performance
   - Segurança
   - Usabilidade
   - Escalabilidade
   - Nota Geral
8. Pergunte se desejo alguma melhoria ou correção relacionada ao assunto, considerando qualquer uma das pastas/conversas do projeto.
```
