# Skill — UI/UX Conservadora

## Função

Melhorar o visual, a experiência de uso e a responsividade sem alterar regras de negócio ou sincronismo do sistema.

## Objetivo

Evoluir o design com segurança, mantendo a lógica existente funcionando exatamente como antes.

## Aplicar quando

Use esta Skill para:

- melhorar layout;
- melhorar cards;
- melhorar botões;
- ajustar espaçamentos;
- melhorar tipografia;
- melhorar contraste;
- criar hierarquia visual;
- melhorar responsividade;
- melhorar modais;
- melhorar dashboards;
- melhorar tabelas;
- aplicar aparência SaaS profissional.

## Regras obrigatórias

1. Não alterar regra de negócio.
2. Não alterar cálculo.
3. Não alterar status.
4. Não alterar contagem de sessões.
5. Não alterar filtros lógicos.
6. Não alterar estrutura do banco.
7. Não alterar integração com WhatsApp.
8. Não alterar fluxo de dados entre abas.
9. Não remover informações importantes da tela.
10. Toda alteração deve ser incremental e reversível.

## Permitido

- Ajustar CSS.
- Ajustar responsividade.
- Melhorar espaçamento.
- Melhorar alinhamento.
- Modernizar botões.
- Criar estados visuais.
- Melhorar contraste.
- Separar visualmente informações críticas.
- Criar microinterações leves.
- Melhorar legibilidade.
- Melhorar experiência em desktop, tablet e celular.

## Não permitido

- Reescrever componentes inteiros sem necessidade.
- Mudar nomes de campos usados pela lógica.
- Alterar estados globais.
- Alterar hooks de dados.
- Alterar estrutura de pacotes, sessões ou pagamentos.
- Alterar lógica do robô WhatsApp.
- Misturar design com regra de negócio.

## Critérios de qualidade

- Interface limpa.
- Hierarquia visual clara.
- Informação financeira bem destacada.
- Status compreensível.
- Botões alinhados.
- Responsividade real.
- Layout sem quebra em tela pequena.
- Sem sobreposição de elementos.
- Sem fontes pequenas demais.
- Sem excesso de cores.
- Paleta existente preservada.
