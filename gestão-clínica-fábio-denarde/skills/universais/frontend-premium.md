# Skill — Front-End Premium

## Função

Elevar a qualidade visual e interativa do sistema para um padrão profissional de SaaS moderno.

## Objetivo

Criar uma experiência refinada, responsiva, clara e confiável, sem sacrificar performance ou estabilidade.

## Aplicar quando

Use esta Skill para:

- landing pages;
- dashboards;
- sistemas SaaS;
- páginas internas;
- cards;
- modais;
- tabelas;
- formulários;
- navegação;
- responsividade;
- microinterações.

## Diretrizes

1. Trabalhar com design system consistente.
2. Priorizar legibilidade.
3. Usar hierarquia visual clara.
4. Criar espaçamento respirável.
5. Evitar poluição visual.
6. Aplicar responsividade mobile-first quando adequado.
7. Garantir boa experiência em desktop, tablet e celular.
8. Usar animações sutis e funcionais.
9. Evitar efeitos pesados.
10. Preservar identidade visual existente quando o usuário aprovar a paleta.

## Melhorias recomendadas

- Cards com profundidade sutil.
- Botões com estados hover/focus/active.
- Ícones bem alinhados.
- Grids responsivos.
- Tabelas com melhor leitura.
- Badges de status.
- Modais mais ricos.
- Empty states.
- Loading states.
- Feedback visual para ações.
- Alertas claros.
- Tipografia com escala consistente.

## Restrições

1. Não alterar lógica.
2. Não mexer em dados reais.
3. Não refatorar arquitetura sem autorização.
4. Não alterar integrações.
5. Não criar dependências novas sem justificar.
6. Não piorar performance.
7. Não quebrar acessibilidade.

## Checklist

- O layout continua funcional em 1366px?
- O layout funciona em 1920px?
- O layout funciona em notebook?
- O layout funciona em tablet?
- O layout funciona em celular?
- Os botões continuam acessíveis?
- As informações importantes continuam visíveis?
- Os textos estão legíveis?
- Existe contraste suficiente?
- A alteração não mexeu na lógica?
