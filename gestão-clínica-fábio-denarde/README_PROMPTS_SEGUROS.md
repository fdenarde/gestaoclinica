# Prompts Seguros para Codex

Este pacote adiciona dois prompts prontos na pasta `prompts/` do projeto.

## Arquivos

```text
prompts/
├── prompt-padrao-seguro-codex.md
└── prompt-curto-seguro-codex.md
```

## Como usar

Copie o conteúdo do prompt desejado e cole no Codex.

## Quando usar cada um

### prompt-padrao-seguro-codex.md

Use quando a tarefa envolver:

- Agenda;
- Sessões;
- Pacotes;
- Pagamentos;
- Pacientes;
- Firebase;
- Robô WhatsApp;
- correção de sincronismo;
- deploy;
- alteração crítica.

### prompt-curto-seguro-codex.md

Use no dia a dia para economizar tokens, principalmente em:

- análise simples;
- pequenas melhorias visuais;
- ajuste de responsividade;
- organização de layout;
- revisão sem alteração crítica.

## Segurança

Este pacote contém apenas arquivos Markdown.
Ele não altera código, não faz deploy, não modifica Firebase e não envia WhatsApp.
