# Checklist — Testes de Regressão da Clínica

Use depois de qualquer alteração no projeto.

## 1. Pacientes

- [ ] Abrir lista de pacientes.
- [ ] Buscar paciente.
- [ ] Abrir detalhes.
- [ ] Editar informação simples.
- [ ] Conferir responsável.
- [ ] Conferir telefone.
- [ ] Conferir observações.
- [ ] Conferir histórico.

## 2. Agenda

- [ ] Criar agendamento futuro.
- [ ] Abrir agendamento futuro.
- [ ] Editar horário.
- [ ] Marcar como realizada.
- [ ] Marcar falta.
- [ ] Cancelar.
- [ ] Conferir se histórico foi atualizado.
- [ ] Conferir se não duplicou sessão.

## 3. Sessões

- [ ] Conferir contagem de sessões.
- [ ] Conferir número da sessão.
- [ ] Conferir pacote atual.
- [ ] Conferir sessão realizada.
- [ ] Conferir falta.
- [ ] Conferir cancelamento.
- [ ] Conferir sessões futuras.

## 4. Pagamentos

- [ ] Conferir receita bruta.
- [ ] Conferir saldo a receber.
- [ ] Conferir parcelas pagas.
- [ ] Conferir parcelas pendentes.
- [ ] Conferir paciente quitado.
- [ ] Conferir paciente com pendência.
- [ ] Conferir relação com pacote atual.

## 5. Robô WhatsApp

- [ ] Rodar apenas relatório offline.

- [ ] Testar em desktop.
