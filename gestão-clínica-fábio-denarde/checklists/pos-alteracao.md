# Checklist — Pós-Alteração

Use depois de qualquer edição no projeto.

## Resumo

- [ ] O que mudou foi descrito.
- [ ] Arquivos alterados foram listados.
- [ ] O que foi preservado foi informado.
- [ ] Riscos residuais foram informados.
- [ ] Como testar foi explicado.

## Validação

- [ ] Sistema abriu.
- [ ] Aba alterada abriu.
- [ ] Outras abas continuam abrindo.
- [ ] Não houve erro no console.
- [ ] Dados reais continuam visíveis.
- [ ] Não houve perda de histórico.
- [ ] Não houve alteração de status indevida.
- [ ] Não houve alteração de pagamento indevida.
- [ ] Não houve envio WhatsApp.
